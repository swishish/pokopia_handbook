# 官方繁中種族名

寶可夢**種族**中文以 [台灣寶可夢官方網站圖鑑](https://tw.portal-pokemon.com/play/pokedex/) 為準。實作上圖鑑資料的 `name_species_tc` 取自 PokeAPI `pokemon_species_names` 的 **zh-Hant**（`local_language_id=4`，iso3166=tw），與台灣官網圖鑑譯名一致。不用機器翻譯、簡體或日文漢字硬譯。

卡片名若日後出現，另查 [訓練家網站卡片搜尋](https://asia.pokemon-card.com/tw/card-search/list/)。

- 夢島傳說／玩偶：見 `official-names.json`（抽樣核對官網）。
- 圖鑑全表：見 `pokedex.json` 的 `name_species_tc`、`portal_url`。
- 括號內的樣子／本作用例（帕底亞的樣子、博士、尖峰、青苔、音響等）是形態或 NPC 標籤，不是官網種族本名。

本站不重抄官方圖鑑敘述。核對日：2026-10-12。
