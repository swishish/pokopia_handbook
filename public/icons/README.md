# 圖示來源

- `types/*.svg`：vendored from [partywhale/pokemon-type-icons](https://github.com/partywhale/pokemon-type-icons) (MIT). License copy in `types/LICENSE`.
- `flavors/*.svg`、`habitats/*.svg`：本站自繪圓形小標，奶油紙底＋墨線。不是從 Pokopia Companion 或其他粉絲站抓來的素材。
- `cloud-islands/*.svg`：本站自繪奶油紙示意，只在沒有可用公開截圖時當後備。實際卡片縮圖在 `public/cloud-islands/*.jpg`，來源寫在 `cloud-islands.json` 的 `preview_sources`。之後可換成自己的 Switch 截圖，來源一併改。
